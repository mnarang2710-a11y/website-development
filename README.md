#  Café Lota – Artisanal Regional Indian Dining

A modern café website created using AI-powered website development tools during the **AI-Powered Website Build & Deploy Workshop**, organised by **Future Makers Hub (FMH)**.

The project demonstrates how AI tools can accelerate website development, improve the web experience, and integrate backend services using Supabase.

##  Live Demo

**Website:** https://cafe-lota.ai.studio

##  Project Overview

Café Lota is a web development project inspired by the concept of artisanal regional Indian dining. It was developed as a hands-on implementation of AI-powered website building and deployment.

The project also includes a **Supabase backend connection**, providing practical exposure to integrating frontend applications with backend services.
